# VhostFactory

Automatic Nginx configuration and SSL certificate provisioning for Ubuntu servers.

## Features

- Zero-Touch Setup — Just create a folder, everything else is automatic
- SSL Certificates — Automatic Let's Encrypt provisioning
- Auto-Renewal — SSL certificates renewed automatically before expiration
- Multi-Stack — Supports PHP, Node.js, and static websites
- Safe Deletion — Only removes auto-generated configs, protects manual ones
- Comprehensive Logging — Full audit trail of all operations

## Requirements

- Ubuntu 20.04+
- Python 3.9+
- Nginx
- Certbot (`apt install certbot python3-certbot-nginx`)

## Installation

```bash
git clone https://github.com/yourusername/vhostfactory.git
cd vhostfactory
sudo ./install.sh
```

## Configuration

Edit `/etc/vhostfactory/config.yml`:

```yaml
watch_directory: /var/www
nginx_sites_available: /etc/nginx/sites-available
nginx_sites_enabled: /etc/nginx/sites-enabled
php_fpm_socket: /run/php/php-fpm.sock
node_default_port: 3000
certbot_email: admin@example.com
log_file: /var/log/vhostfactory.log
log_level: INFO
```

## Usage

### Creating a Website

```bash
mkdir -p /var/www/example.com
# Upload website files
# VhostFactory automatically detects stack and configures everything
```

### Stack Detection

- **PHP**: `index.php` present → PHP-FPM setup
- **Node.js**: `package.json` present → Reverse proxy on port 3000
- **Static**: No special files → Static website served from directory

### Deleting a Website

```bash
rm -rf /var/www/example.com
# VhostFactory automatically removes Nginx config and SSL cert
```

## Service Management

```bash
# Start service
sudo systemctl start vhostfactory

# Enable on boot
sudo systemctl enable vhostfactory

# Check status
sudo systemctl status vhostfactory

# View logs
sudo journalctl -u vhostfactory -f
```

## Architecture

```
VhostFactory Daemon
├── Watchdog Monitor (filesystem events on /var/www)
├── Stack Detector (PHP/Node/Static)
├── Nginx Manager (config generation & reload)
└── SSL Manager (certbot integration)
```

## Logging

Logs written to `/var/log/vhostfactory.log` (10MB rotation, 5 backups).

```bash
tail -f /var/log/vhostfactory.log
```

## Safety Features

- Auto-generated configs marked with `# AUTO-GENERATED by vhostfactory - DO NOT EDIT`
- Manual configs never touched by deletion handler
- SSL failure is non-fatal — site stays up on HTTP

## Troubleshooting

**Service won't start:**
```bash
journalctl -u vhostfactory -n 50
```

**Config not generated:** Check log, verify Nginx path in config.yml.

**SSL not created:** Verify certbot is installed and certbot_email is set in config.yml.
